# Story : terminer le combat à tout moment

**En tant que** joueur solo
**Je veux** mettre fin au combat quand je le décide
**Afin de** garder la main sur le récit

## Acceptance

- L'action « terminer le combat » est disponible à tout moment du combat.
- Une fois le combat terminé, il n'y a plus de tours, et les créatures restent sur la carte avec leurs PV.
- Le journal indique la fin du combat.
