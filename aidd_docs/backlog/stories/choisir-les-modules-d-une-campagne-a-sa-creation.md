# Story : choisir les modules d'une campagne à sa création

**En tant que** joueur solo
**Je veux** choisir les modules actifs en créant une campagne
**Afin de** n'avoir dans mon Carnet que les aides solo que j'utilise pour cette histoire

## Acceptance

- Le formulaire de création de l'accueil liste les modules installés, chacun avec une case à cocher.
- La campagne créée n'affiche dans son Carnet que les panneaux et les sections des modules cochés.
- Aucun module coché : le Carnet marche comme aujourd'hui sans module, sans colonne de modules.
- Les campagnes qui existent déjà gardent Mythic actif.
- Le choix survit au redémarrage du serveur.
- Les routes d'un module inactif refusent l'appel pour cette campagne.
