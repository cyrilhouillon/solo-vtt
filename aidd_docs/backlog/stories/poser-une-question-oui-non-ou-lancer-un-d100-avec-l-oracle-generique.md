# Story : poser une question oui/non ou lancer un d100 avec l'oracle générique

**En tant que** joueur solo
**Je veux** un oracle sans marque qui réponde oui ou non à 50/50, ou qui lance un d100
**Afin de** trancher sans dépendre d'un système commercial

## Acceptance

- Le module « Oracle » a son panneau dans le Carnet.
- Je pose une question (texte facultatif) : le jet répond oui ou non, à chances égales.
- Je lance un d100 : le résultat va de 1 à 100.
- Le jet s'écrit dans la page ouverte comme pour Mythic : au curseur, ou à la fin si la page est verrouillée. La question et le jet sont écrits avec le résultat.
- Sans page ouverte, le jet est refusé avec la raison, avant tout tirage.
- C'est un module : sans lui, le Carnet marche comme avant.
