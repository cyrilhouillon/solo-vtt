# VCS

## Configuration

- Branche principale : `main` (le dépôt local est encore sur `master`, à renommer).
- Plateforme : GitHub, `cyrilhouillon/solo-vtt`.
- Tickets : aucun outil pour l'instant ; GitHub Issues si le besoin apparaît.
- Hooks : aucun.

## Branches

- Une branche par feature, fusionnée par pull request.
- Format : `type/description-courte`.
- Types : `feat`, `fix`, `refactor`, `chore`, `docs`, `test`.

## Commits

- Convention : Conventional Commits.
- Format : `type(scope): description`, scope = zone du code (`core`, `attack`, `rules`…).
- Règles : en français, à l'impératif, en minuscules, sans point final.

## Stratégie de commit

L'IA committe automatiquement : `after phase`
